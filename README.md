## 📊 Project — Employee Data Analysis

The project analyzes employee information stored in a CSV file using **Python and Pandas**.

### 📌 Dataset

The project uses an employee dataset containing:

- Employee ID
- Employee Name
- Department
- Salary

**Dataset File:** `employee_data.csv`

---

## ⚙️ Features

### 1. 📂 Load Employee Data

Loads employee information from a CSV file using Pandas.

### 2. 💰 Calculate Average Salary

Calculates and displays the average salary of all employees.

### 3. 🏢 Department Analysis

Counts the number of employees in each department.

### 4. 🔍 Salary Filtering

Allows the user to enter a salary threshold and displays employees earning above that amount.

### 5. 📄 Export Results

Exports the filtered employee records to a new CSV file.

**Output File:** `filtered_employees.csv`

---

## 🛠️ Technologies Used

- Python 3
- Pandas
- CSV
- GitHub

---

## ▶️ How It Works

1. Load `employee_data.csv`.
2. Read the employee data using Pandas.
3. Calculate the average salary.
4. Count employees by department.
5. Enter a salary threshold.
6. Filter employees above the threshold.
7. Export the filtered results to `filtered_employees.csv`.
